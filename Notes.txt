Analysing Linear Search Algorithm:
	The solution for Linear Search is Brute Force Technique.
	Brute Force is the technique that come usually naturally without having to apply any specific Math rule or formula.
	Thus there is no inventor or author for these solutions.

	Best Case Scenario: Element is found at 1st index, because in this case there is only one iteration
	Thus Best Case Efficiency for Linear Search is O(1) -> Read as big-Oh of One

	If in case the element is not found or it is found at the last possible index (last position) then it is the Worst case scenario and thus 	the WCE would be O(n), where n is the size of the list.

	If in case the element is found some where at the mid of the list, then can coin the term Avg Case Efficiency and that would be O(n).

Characteristics of Big-Oh:
	1. It is used usually to find WCE. However, we can also find the other 2. I
	2. The Big-Oh always depends on the i/p size and gives the efficiency in order of the i/p size, say 'n'.
	3. The Big-Oh is here to tell us the Order in which the algorithm is. It's duty is Not to give the exact efficiency of the algorithm.
	4. The Big-Oh gives the efficiency in terms of 'n'
	5. The Big-Oh uses the Math functions such as factorial, logarithmic, sq-root etc.

BINARY SEARCH:

	Strategy: Divide and Conquer
	What it is used for: To search an element in a list (An array and not a linked list)
	Pre-requisite: It expects the List to be sorted fully
	Solution:
	Go to mid element of the list and check if it is the search
	If yes,
		then the search can stopped
	If not,
		then check if the element is less than the mid element
		(i.e. if the element is in 1st half of the list)
	if yes,
		then set the search area to 1st half of the list
	if not,
		set the search area to the 2nd half 
	Repeat the above steps until at least one element is left

	Pseducode:
	do this:
		mid_position = (1st position + last position) // 2
		if element == list[mid_position] then
			stop the search and if you wish, return
			mid_position
		else
			if element < list[mid_position] then
				list = 1st half of list
			else:
				list = 2nd half of list

	Assume number of iterations of the while loop is X
	
	n	n/2	n/4	n/8 ...............	8	4	2	1
	2^(X-1) 2^(X-2)					2^3	2^2	2^1	2^0

	2^(X-1) = n
	2^(X) = n		//We ignore -1  because Big Oh gives approx. efficiency
	X = O(log n)

	for i in range(n):
		element = numbers[i]
		j = i - 1
		while j >= 0 and element < numbers[j] :
			numbers[j+1] = numbers[j]
			j -= 1	
		numbers[j+1] = element

	Worst Case Efficiency: O(n^2)
